# Sue Stephenson — Marketing Site

Single-page marketing site built with Next.js (App Router) and Tailwind CSS.

## Development

```bash
npm install
npm run dev
```

## Static build

```bash
npm run build
```

Outputs a static site to `out/`, ready to deploy to any static host (Vercel,
Netlify, GitHub Pages, S3, etc.).

## Adding the headshot

Drop the portrait photo into `public/images/headshot.jpg`. It's used in both the
hero section and the about section.
